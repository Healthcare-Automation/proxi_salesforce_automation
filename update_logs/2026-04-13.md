### How to add future entries

1. Create a new file per day you log work: `YYYY-MM-DD.md`, **or** append to that day’s file if you already have one.
2. Use short sections per change, for example:

```markdown
## Short title of change

- **When:** YYYY-MM-DD (optional if the filename is the date)
- **Area:** e.g. `src/utils/`, tests, notebooks, docs
- **What:** Bullet points — behavior, files touched, rationale
- **Notes:** Optional — follow-ups, risks, links to PRs/commits
```

3. Log anything you care to remember: fixes, refactors, new tests, pipeline behavior, Salesforce field mapping, etc.
